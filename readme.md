## 🇮🇩 Deskripsi

Project ini adalah web app untuk memvisualisasikan berbagai **sorting algorithm** dengan cara yang unik:

* Menggunakan **potongan gambar meme** sebagai bar
* Animasi sorting real-time
* Sound effect berdasarkan nilai data
* Bisa langsung **record video 9:16 (Reels / TikTok ready)**

Cocok untuk:

* Konten edukasi
* TikTok / Reels tech content
* Belajar algoritma secara visual

---

## 🇬🇧 Description

This project is an interactive web app to visualize **sorting algorithms** in a fun way:

* Uses **meme slices** as visual bars
* Real-time sorting animation
* Audio feedback per operation
* Built-in **9:16 recording (Reels/TikTok ready)**

Perfect for:

* Educational content
* Tech social media content
* Visual learning

---

## 🚀 Features

### 🎯 Algorithm Support

* Bubble Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort
* Heap Sort
* Radix Sort
* Shell Sort

---

### 🎨 Visual Customization

* Custom meme (upload / URL)
* Adjustable bar count
* Speed control
* Background color
* Code panel color
* Font customization (title & code)

---

### 💻 Code Preview

* Multi-language support:

  * Python
  * JavaScript
  * C++
  * Java

---

### 🔊 Audio System

* Sound generated per comparison/swap
* Frequency based on value

---

### 🎥 Recording System

* Record directly from browser
* Auto crop to **9:16**
* Export as `.webm`
* Optimized for:

  * TikTok
  * Instagram Reels
  * YouTube Shorts

---

## 🧠 How It Works

1. Generate array (randomized meme slices)
2. Choose algorithm
3. Run animation
4. Each operation:

   * Updates visual bar
   * Plays sound
5. Optional:

   * Record the whole process

---

## ▶️ Usage

### 1. Start Visualization

```text
Klik tombol "Animasi"
```

### 2. Record Video

```text
Klik "Rekam HD"
→ Pilih "Tab Ini"
→ Centang "Share Audio"
```
